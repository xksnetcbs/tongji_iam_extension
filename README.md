# 同济大学统一身份认证自动登录 Edge 浏览器插件

Code Generated by codex.

## 食用方法

1. 去 release 里下载压缩包（或者Download source code(.zip)也行）
2. 随便解压到一个位置
3. 编辑 `config.js` ，将 `你的用户名` 和 `你的密码` 替换成你真实的用户名和密码
4. 打开 `edge://extensions/`，点击 `加载解压缩的拓展` ，选择你刚刚解压的文件夹，启用插件
5. 配置完成，可以打开 `https://1.tongji.edu.cn` 测试

## 承诺：你的登录信息只会保留在本地插件中
